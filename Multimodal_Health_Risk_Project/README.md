# Multimodal Health Risk Prediction Using Explainable AI

## About the Project

The **Multimodal Health Risk Prediction System** is a machine-learning-based healthcare application developed to analyse different types of health information and estimate possible disease risks.

Assessing a person's health requires more than looking at a single medical measurement. Laboratory results, medical history, vital signs, and imaging findings can each provide useful information. This project brings these different types of information together and uses machine-learning models to analyse them.

The application focuses on four health conditions:

- Diabetes
- Heart Disease
- Breast Cancer
- Bronchitis

It provides disease predictions, risk-level classification, model explanations, future-risk information, and general preventive guidance through a Flask-based web application.

This project was developed as an academic prototype to explore the use of Machine Learning and Explainable AI in healthcare analytics.

## Key Features

- **Multimodal Health Data Integration:** Combines laboratory measurements, medical history, vital signs, and structured imaging findings.
- **Disease Prediction:** Predicts one of four disease categories using trained machine-learning models.
- **Disease Probability:** Displays the probability values generated by the disease prediction model.
- **Risk Classification:** Classifies the predicted risk into Low, Medium, and High categories.
- **Explainable AI:** Uses SHAP to identify and explain the features contributing to model predictions.
- **Future-Risk Analysis:** Provides an additional possible disease prediction based on the available health information.
- **Prevention Guidance:** Displays general preventive suggestions related to the prediction.
- **Interactive Dashboard:** Presents results through a user-friendly web interface.
- **PDF Report Generation:** Allows users to download their assessment as a PDF report.

## Machine Learning Algorithms

The project compares multiple machine-learning algorithms to identify suitable models for the prediction tasks.

The algorithms considered include:

1. Logistic Regression
2. Random Forest
3. Gradient Boosting
4. Extra Trees Classifier
5. Hist Gradient Boosting

The models are evaluated using the following performance measures:

- Accuracy
- Precision
- Recall
- Weighted F1-score

The model with the highest weighted F1-score is selected separately for each prediction task.

## System Workflow

1. The user enters health information through the web application.
2. The submitted information is validated and preprocessed.
3. The available health features are combined for model prediction.
4. The trained disease model predicts the disease category and probability.
5. A separate model predicts the risk category.
6. SHAP is used to explain the contributing features.
7. The future-risk model generates an additional disease prediction.
8. General preventive suggestions are displayed.
9. The results are presented on the dashboard.
10. The user can download the assessment as a PDF report.

## Input Data

The application works with the following categories of health information:

**1. Laboratory Measurements**
- Glucose
- HbA1c
- Cholesterol
- HDL and LDL
- Triglycerides
- Hemoglobin
- Creatinine
- WBC
- Platelets

**2. Medical History**
- Family history
- Previous diseases
- Smoking history
- Alcohol history
- Disease-related medical history

**3. Vital Signs**
- Blood pressure
- Heart rate
- Respiratory rate
- Oxygen saturation (SpO2)
- Temperature
- BMI
- Height and weight

**4. Imaging-Related Information**
- Chest X-ray findings
- Mammogram findings
- Imaging reports
- Image categories

The imaging component uses structured findings and report information rather than directly processing raw medical images.

## Installation and Setup

### Step 1: Clone the Repository

```bash
git clone https://github.com/Yadunandan522005/Multimodal_Health_Risk_Predictor.git
```

### Step 2: Open the Project Folder

```bash
cd Multimodal_Health_Risk_Predictor
```

### Step 3: Create a Virtual Environment

```bash
python -m venv .venv
```

### Step 4: Activate the Virtual Environment

For Windows:

```bash
.venv\Scripts\activate
```

### Step 5: Install Dependencies

If a `requirements.txt` file is available:

```bash
pip install -r requirements.txt
```

### Step 6: Run the Application

Run the Flask application using its main Python entry-point file. For example, if the main file is `app.py`:

```bash
python app.py
```

Open the local address displayed in the terminal in your web browser.

**Note:** The required trained model files and dataset must be available in their expected project locations before running the application.

## Project Objectives

- To combine multiple categories of healthcare information for disease-risk analysis.
- To develop machine-learning models for four selected health conditions.
- To classify model-predicted risk into three categories.
- To make model predictions easier to understand through Explainable AI.
- To provide additional future-risk information and preventive suggestions.
- To develop a web-based application for displaying and downloading assessment results.

## Limitations

- The application is an academic prototype and has not undergone clinical validation.
- Predictions depend on the quality and availability of the submitted health information.
- Structured imaging findings are used instead of direct raw-image analysis.
- Future-risk predictions represent model-based estimates and do not establish actual disease progression.
- The risk categories are model predictions and are not clinically established risk levels.
